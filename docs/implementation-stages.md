# Этапы реализации AutoDocGen

## 1. База данных

### Что делаем
- SQLAlchemy-модели: `users`, `analysis_runs`, `analysis_files`, `analysis_results`.
- Асинхронное подключение к PostgreSQL.
- Инициализация схемы через `Base.metadata.create_all`.

### Критерий готовности
- После запуска backend можно сохранить запуск анализа, список файлов и итоговый Markdown-результат.

## 2. Логика Ollama

### Что делаем
- Принимаем 10-15 файлов в endpoint `/api/v1/analyze`.
- Нормализуем текст файлов и собираем единый prompt.
- Отправляем prompt в Ollama (`/api/generate`) и получаем Markdown-ответ.

### Критерий готовности
- Endpoint возвращает структурированный "Технический анализ" в поле `analysis_markdown`.

## 3. Фронтенд

### Что делаем
- Макет: sidebar + drag-and-drop + большое поле результата.
- Загрузка 10-15 файлов и вызов backend-API.
- Действия `Сохранить` и `Повторить`.

### Критерий готовности
- Пользователь загружает файлы, нажимает `Запуск` и видит Markdown-результат в интерфейсе.
