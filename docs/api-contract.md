# API контракт AutoDocGen

## Endpoint

- `POST /api/v1/analyze`
- Content-Type: `multipart/form-data`

## Поля запроса

- `files`: массив файлов (`UploadFile`), строго от 10 до 15 шт.
- `model`: строка, имя модели Ollama (пример: `deepseek-r1:latest`).
- `output_format`: строка (`md` по умолчанию).
- `user_id`: число, опционально.

## Валидации

- Допустимые расширения: `.py`, `.js`, `.ts`, `.md`, `.txt`, `.json`.
- После фильтрации должно остаться минимум 10 текстовых файлов.
- Ограничение размера текста:
  - до `25000` символов на файл;
  - до `300000` символов суммарно.

## Успешный ответ (`200`)

```json
{
  "run_id": 14,
  "files_count": 12,
  "model": "deepseek-r1:latest",
  "output_format": "md",
  "analysis_markdown": "# Технический анализ\n..."
}
```

## Ошибки

- `400`: ошибка валидации входных файлов/параметров.
- `502`: ошибка обращения к Ollama или пустой ответ модели.
